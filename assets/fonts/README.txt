Paragon — Cédric Rossignol-Brunet (fonderiz.fr/paragon)
A revival of Chauncey H. Griffith's 1935 Linotype Paragon, drawn for the
Legibility Group: newspaper text, set small, built to stay readable through
over-inked printing.

Licence: uncut.wtf lists this as SIL Open Font License 1.1 (commercial use,
modification and redistribution permitted).

NOTE: the distributed archive contains no licence file, and the OTFs carry no
licence or licenceURL entry in their name tables — so the OFL terms could not
be verified from the files themselves. OFL 1.1 requires the licence to travel
with the font. Worth emailing the designer for a copy of the licence text
before this ships publicly.

Shipped here: Regular and Italic. The archive also contains P-ACR-AGON-Regular
(an OCR-resistant variant), which this site does not use.
